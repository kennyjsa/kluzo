# 0005. Go como linguagem do núcleo

- Status: aceito
- Data: 2026-11-07

## Contexto

O trabalho do Kluzo é supervisão de processos, I/O e estado, não CPU. O ecossistema do autor (minvault, minscaler) e as referências estudadas (koryph, belay, Pinard, Gas Town, Detent) são em Go.

## Decisão

Núcleo em Go, num binário único, com SQLite sem cgo (modernc.org/sqlite) e a web em Vue embutida via embed.

## Consequências

- Distribuição simples.
- Máquinas de estado exigem disciplina (tipos fechados e testes de transição), já que Go não tem enums exaustivos.
