# v0.1 · Registro das rodadas

Uma entrada por rodada de desenvolvimento: o que entrou em `milestone/v0.1`, o veredito do review do PO e as perguntas do dev (Q) resolvidas nos contratos. O escopo e os critérios de cada item ficam em [v0.1.md](v0.1.md). Este arquivo registra o que aconteceu.

**Como ler.** Cada rodada tem um ou mais commits de merge na `milestone/v0.1` e, quando houve perguntas, um commit na `main` que atualiza os contratos. Um item com sufixo (`2b`, `9b`…) é a rodada de correção dos achados do review anterior. As entradas antes de 09/11 foram reconstruídas a partir do `git log`. Nelas os achados aparecem resumidos pelo que a correção mudou.

**Ciclo.** O PO escreve o prompt de cada rodada, uma sessão de dev implementa, e o PO revisa a branch inteira, sem review parcial. Código duplicado e código morto bloqueiam o merge. O merge na `main` é sempre humano, no fim da v0.1.
