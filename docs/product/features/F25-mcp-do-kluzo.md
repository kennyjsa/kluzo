# F25 · MCP do Kluzo

- **Grupo:** G. Plataforma
- **Status:** planejada

- **O quê:** o canal agente → Kluzo.
- **Comportamento:** ferramentas `kluzo_context`, `kluzo_changes`, `kluzo_decision`, `kluzo_propose_node`, `kluzo_ask` e `kluzo_result`, com permissões por papel.
- **Contexto de código:** as ferramentas `kluzo_code_*` são da [F31](F31-mapa-de-codigo.md).
- **Aceite:** um papel sem permissão recebe erro ao chamar uma ferramenta fora do escopo dele.
- **Versão:** v0.2 (na v0.1, o resultado vem pela saída estruturada do harness).
